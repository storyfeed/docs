# Roadmap

The 1.0 docs teach every stable Storyfeed API with examples generated from real
Storyfeed output, versioned alongside core.

**Versions are milestones, not dates.**

## The countdown to 1.0

Each version below is a GitHub milestone holding its concrete issues. Issue
titles start with the version they target, such as `[0.21]`.

- [ ] **[v0.21 — Payload reference](https://github.com/storyfeed/docs/milestone/6).**
      The payload reference is marked stable alongside core's Payload v1.
- [ ] **[v1.0 — Docs for 1.0](https://github.com/storyfeed/docs/milestone/4).**
      Every docs example is generated by core at build time, and every stable
      API is documented.
