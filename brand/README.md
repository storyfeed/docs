# Storyfeed press kit

The Storyfeed mark, wordmark and share images, ready to use.
[Download everything as one ZIP](storyfeed-press-kit.zip).

Lowercase **storyfeed** is the wordmark; **Storyfeed** is the name in prose.

## What's included

| folder | contents |
|---|---|
| `marks/` | the mark in light, dark, mono and reverse, as SVG and PNG from 16 to 1024 px, plus simplified `-small` SVGs for favicon sizes |
| `lockups/` | the mark with the wordmark: horizontal and stacked, light, dark, mono and reverse; `word-*` is the wordmark alone |
| `social/` | share images, 2400×1200 and a 1200×630 crop, light and dark, as SVG, PNG and JPG |
| `avatars/` | square profile images, contained (on a field) or transparent, light and dark |
| `icons/` | favicons, the Apple touch icon and app icons |
| `banners/` | repository banners, and the animated README banner with static PNG and SVG stills |
