# Compatibility

Storyfeed requires PHP 8.4 or newer and Laravel 12 or 13.

## Requirements

| | |
|---|---|
| PHP | **8.4 and newer** |
| Laravel | 12 and 13 |
| Databases | MySQL, PostgreSQL, SQLite, SQL Server |

## Tested Environments

Storyfeed is tested on Ubuntu and Windows, on PHP 8.4 and 8.5 with Laravel 12
and 13, against both the lowest and the latest allowed dependency versions.
