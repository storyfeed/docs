# Compatibility

Storyfeed requires PHP 8.4 or newer and Laravel 12 or 13.

## Requirements

| | |
|---|---|
| PHP | **8.4 and newer** |
| Laravel | 12 and 13 |
| Databases | MySQL, PostgreSQL, SQLite, SQL Server |

## Tested Environments

The CI matrix runs on Ubuntu and Windows, with PHP 8.4/8.5 × Laravel 12/13 × prefer-lowest/prefer-stable.
An additional Ubuntu job runs the suite in parallel on PHP 8.5 and Laravel 13.
